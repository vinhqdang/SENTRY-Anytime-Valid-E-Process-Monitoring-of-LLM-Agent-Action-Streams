# Manuscript

Springer Nature `sn-jnl` (author-year, `sn-basic` style) manuscript:
**"Conformal Surprisal Fusion for Detecting Prompt-Injection Compromise in LLM
Agent Traces."** Prepared for *Discover Artificial Intelligence* (Springer Nature). An earlier
submission to *Discover Computing* was withdrawn by that journal during
editorial processing, before review.

## Build

```bash
pdflatex sentry_ml
bibtex   sentry_ml
pdflatex sentry_ml
pdflatex sentry_ml
```

Requires a TeX Live installation with the `sn-jnl` document class, `algorithm`/
`algpseudocode`, `booktabs`, `amsmath`, `amsthm` and `placeins` (all standard).
Competing interests, funding, data availability, and generative-AI-use
declarations are embedded directly in `sentry_ml.tex` (Springer's required
format), so there is no separate declarations file.

## Figures

Every figure in the paper is generated by one of the two scripts; none is
hand-drawn. From the repo root:

```bash
PYTHONPATH=. SENTRY_IL_MODE=llm SENTRY_JUSTIFY=1 python manuscript/make_figures.py
PYTHONPATH=. python manuscript/make_paper_figures.py
```

`make_figures.py` reads the collected trajectories in `../real_data/` and the
committed multi-seed results; `make_paper_figures.py` reads
`../real_data/results_fused.json` and
`../real_data/results_ceiling_per_corpus.json`. Both are run by `../reproduce.sh`.

## References

Every entry was checked against the arXiv API (title, full author list, date) or
Crossref (DOI, volume, pages) and carries a DOI or URL; author lists are complete
rather than truncated. `wang2025agentarmor` is deliberately cited as **v1**,
because the operating point quoted in the paper appears in v1 only and is absent
from later versions — a `note` field records this.

## A note on earlier versions

Earlier drafts, and the file sets prepared for IEEE TDSC, Computers & Security,
JISA and ESWA before those submissions were retargeted, are retained in git
history only. Some report numbers computed with an **inverted** attack-success
label (AgentDojo's `security` flag is the injection task's success, so
`security=True` means the agent was compromised). Those numbers were therefore
measured on the resisted class and should not be read as results; the current
paper documents the error and its resolution.
